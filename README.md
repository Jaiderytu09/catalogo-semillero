Catálogo Semillero - Módulo 01

Proyecto desarrollado en Angular 17 (API estable) para la gestión de catálogo de productos con vista de cliente y administrador.

Requisitos previos
- Node.js (v18 o superior)
- Angular CLI v17

Cómo levantar el proyecto
1. Clonar el repositorio:
   `git clone <URL_DE_TU_REPOSITORIO>`
2. Entrar a la carpeta del proyecto:
   `cd catalogo-semillero`
3. Instalar las dependencias:
   `npm install`
4. Iniciar el servidor de desarrollo:
   `ng serve -o`
5. Abrir en el navegador: `http://localhost:4200`

Compilación de producción
Para verificar que compila sin errores ni advertencias:
`ng build`
